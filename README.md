# Interactive Student Management System

A GUI-based application designed to manage student records efficiently through a clean desktop or web interface. Built using Python and **Tkinter / CustomTkinter / Streamlit**, this project demonstrates core Object-Oriented Programming (OOP) principles alongside persistent file storage.

## ✨ Key Features
* **CRUD Operations:** Easily add, update, delete, and search student records.
* **OOP Architecture:** Structured cleanly using classes, inheritance, and polymorphism.
* **Data Persistence:** Automatically stores and retrieves student data using local files.
* **Input Validation:** Prevents crashes and bad data entry using custom exception handling.
* **User-Friendly UI:** Intuitive and responsive interface for seamless navigation.
